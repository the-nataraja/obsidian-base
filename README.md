# 🎓 База знаний ВлГУ

Открытый архив учебных материалов, конспектов и лабораторных работ студентов Владимирского государственного университета.

Проект поддерживается инициативной группой студентов. Наша цель — собрать качественные и структурированные материалы, чтобы облегчить подготовку к парам и сессиям.

---

## 📖 Как читать конспекты (2 способа)

### 🌐 Способ 1: Через веб-сайт (Простой)
Вся наша база автоматически публикуется в виде удобного сайта-энциклопедии:  
👉 **[Перейти на сайт: notes.vlsu-hub.org](https://notes.vlsu-hub.org)**

Здесь есть быстрый поиск, темная тема, красивое отображение формул и удобная мобильная версия. Это лучший способ для чтения на парах или перед экзаменом.

### 🌌 Способ 2: Локально в Obsidian (Для работы офлайн)
База изначально спроектирована для работы в приложении **Obsidian**. Если вы хотите скачать все материалы на компьютер:
1. Нажмите зеленую кнопку **`<> Code`** (вверху справа) ➔ **`Download ZIP`**.
2. Распакуйте скачанный архив в удобную папку на компьютере.
3. Установите [Obsidian](https://obsidian.md/) (это бесплатно).
4. Запустите Obsidian, нажмите **«Open folder as vault»** (Открыть папку как хранилище) и выберите распакованную папку.

## 🗺️ Навигация и условные обозначения

Материалы отсортированы по принципу: `Семестр ➔ Предмет ➔ Тип занятия` (внутри могут быть тематические подпапки). Все папки и файлы названы на английском для корректных ссылок на сайте, но внутри Obsidian и на сайте названия отображаются на русском.

Чтобы с первого взгляда понимать, что находится внутри файла, используются короткие префиксы:

* **`LEC`** — Лекция / конспект лекции.
* **`SEM`** — Практика (разбор задач с семинаров).
* **`LAB`** — Лабораторная работа (готовые отчеты, примеры выполнения).
* **`PST`** — Задачи для решения (Problem Set).
* **`SOL`** — Решения задач (Solution).
* **`TST`** — Рейтинг / контрольная работа.
* **`EXM`** — Экзамен (списки билетов, ответы на вопросы, шпаргалки).

> 📌 **Файлы-оглавления:**  
> В каждой папке есть файл **`_index.md`** — **начинайте чтение с него**. Это главная страница раздела со списком материалов и важной организационной информацией.

## 🤝 Хочешь добавить свой материал? (Для соавторов)

Нашел опечатку? Есть конспект или хороший отчет по лабе, которыми не жалко поделиться с одногруппниками? Мы будем рады твоему вкладу!

В репозитории работает **строгий автоматический бот-модератор**. Он следит за порядком и блокирует изменения с неправильными именами файлов, кириллицей в путях, неподходящими форматами картинок или тяжелыми файлами.

### 📝 План действий:
1. **Изучи правила:** Перед началом работы обязательно прочитай регламент **[CONTRIBUTING.md](CONTRIBUTING.md)**. Там описано, как оформить всё с первого раза без отказа от бота.
2. **Сделай Fork:** Нажми кнопку `Fork` в правом верхнем углу этого репозитория, чтобы создать копию базы в своем аккаунте GitHub.
3. **Скачай и редактируй:** Склонируй свой форк на компьютер (рекомендуем **GitHub Desktop**), открой папку в Obsidian, добавь или исправь материалы.
4. **Отправь PR:** Сделай `commit` и `push` в свой форк, а затем открой **Pull Request** в основной репозиторий. Если проверка бота прошла успешно — мы примем твой материал.
