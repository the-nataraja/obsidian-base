---

> [!info] Как читать названия файлов
> В базе принят строгий стандарт именования. Префиксы означают тип материала:
> * **LEC** — Лекция / конспект лекции
> * **SEM** — Практика (разбор задач с семинаров)
> * **LAB** — Лабораторная работа (отчеты, примеры выполнения)
> * **PST** — Задачи для решения (Problem Set)
> * **SOL** — Решения задач (Solution)
> * **TST** — Рейтинг / контрольная работа
> * **EXM** — Экзамен (списки билетов, ответы, шпаргалки)
