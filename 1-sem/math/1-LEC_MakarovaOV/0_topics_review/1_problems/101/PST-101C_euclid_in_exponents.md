# Задача 1.1 [C] — Алгоритм Евклида в показателях степеней

---

## Условие

Докажите, что для любых натуральных чисел $m, n \in \mathbb{N} = \{1, 2, 3, \dots\}$ выполняется тождество:

$$
\text{НОД}(2^m - 1, \; 2^n - 1) = 2^{\text{НОД}(m, n)} - 1.
$$

В доказательстве строго обоснуйте переход на одном шаге деления с остатком (если $m = nq + r$ при $0 \le r < n$, то $\text{НОД}(2^m - 1, 2^n - 1) = \text{НОД}(2^n - 1, 2^r - 1)$), а также корректно рассмотрите случай, когда одно из чисел делится на другое (то есть $r = 0$).
